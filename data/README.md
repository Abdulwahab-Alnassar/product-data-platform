# Dataset

This project uses the Amazon Sales Dataset:

https://www.kaggle.com/datasets/karkavelrajaj/amazon-sales-dataset

Full raw and processed files stay local. The bundled demo contains 100 product
rows, with user_id/user_name columns removed and review fields blanked. Product
text has a basic email/phone mask. It has two main categories and is not a
representative ML benchmark. These edits do not rewrite older Git history.

The original dataset has no stock quantities. Inventory shown by example events
is synthetic and explicitly labeled; unknown stock remains unknown.
